# Publication and evidence scope

The public repository is a frozen source and proof snapshot from checkpoint 275: 341 certified artifacts with passing saved independent replays at that boundary. `results/catalog.json` binds exact structured statements to their proof and challenge bytes. Parent declarations needed by a proof are embedded in its source. The public replay command checks those bindings and can run a fresh local compiler/axiom audit.

Saved certification and replay metadata describe their measured boundary. A fresh checkout does not inherit the original machine's live receipts, runtime atlas or process state. Use `scripts/replay_results.py --check-only` for content checks and an ordinary replay invocation for a new compiler result. Replaying all artifacts can take substantial local CPU time; use `--limit`, per-proof `--timeout`, sharding and an output report to keep work manageable. Neither mode makes AI requests.

A count of certified artifacts includes routine helpers, known mathematics and equivalent or specialized statements. No original mathematical result or general discovery-rate improvement is established by this snapshot. A new bound should be compared against complete applicable primary statements and reviewed independently; absent literature is a gap. [Investigated originality comparisons](../results/originality-notes.md) and [negative experimental outcomes](negative-results.md) are retained in the release narrative. The repository is a research prototype and has not completed the separate 24-hour qualification gate.

The release includes original source, tests, mathematical seed examples, selected proof sources/challenges and public catalogue metadata. It excludes live checkpoints, model prompts/answers and private traces, raw compiler archives, full papers, extracted paper text, page images, source packs, DIMACS input bytes, virtual environments, Lean binaries and dependency trees. Historical model experiments are summarized; their private request archives are not a public reproduction dataset.

Original project material is Apache-2.0. That license does not relicense upstream software, a cited paper or third-party dataset. The simplest redistribution policy is to retain citations, URLs and independently written mathematical comparisons, while fetching dependencies externally. Any future distribution of copied upstream material must separately retain its applicable license and notices. Public availability and a content hash do not establish redistribution rights; see [third-party notices](../THIRD_PARTY_NOTICES.md).

The DIMACS provenance manifest records source URLs and hashes, but the data files are omitted because this release has no recorded redistribution grant. The optional DIMACS benchmark therefore requires users to obtain matching upstream files separately. Its absence does not prevent proof-corpus replay or the normal research loop.

Publication does not start a research process, send messages to experts or synchronize a local researcher with GitHub. Updates require a new curated snapshot and corresponding checks. The public source cannot expose or spend the maintainer's private AI allowance; optional Codex runs require the user's own authenticated CLI.
